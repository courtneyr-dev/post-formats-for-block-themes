# Screenshots

Inventory of the screenshots used in this documentation: what exists, what each shows, and what still needs to be captured.

Screenshots live in `docs/assets/screenshots/`. Some are generated by the repeatable capture script (`npm run screenshots:docs`, which runs `scripts/capture-docs-screenshots.js` against a disposable WordPress Playground — no Docker needed), some were copied from images already in the repository (`img/`), and the rest are marked "manual needed". WordPress.org listing shots follow the 1390×864 spec in `.wordpress-org/ASSETS-CHECKLIST.md`.

Demo environment for new captures: a block theme (the Playground blueprint uses Twenty Twenty-Five) with the plugin active.
